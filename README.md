# Google Apps Script Assessment Tool

A Google Apps Script project that automates common Google Sheets workflows.

## Features

- Standardizes student names
- Converts raw assessment scores into a standardized rating
- Matches students with their scores
- Posts results to the appropriate monthly column
- Adds custom spreadsheet menu actions

## Technologies

- Google Apps Script
- JavaScript
- Google Sheets

## Privacy

This is a sanitized portfolio version of an internal workflow tool.  
All spreadsheet IDs, organization-specific names, and personal data have been removed.
